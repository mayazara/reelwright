# M3 manual checks

Automated: golden images for every filter, blend mode, colour control and
transform (`cargo test -p rw-render --test golden`), export of looks and
fades, and preview latency
(`RW_PERF=1 cargo test --release -p rw-engine --test preview_latency -- --nocapture`).

1. Add a video, select it. In the preview, drag inside the picture to move
   it, a corner to scale, an edge to stretch, the round knob to rotate (hold
   Shift to snap). Each drag is one undo step.
2. Toolbar: Crop, then drag edges; Flip ↔ / ↕; Rotate 90°; Fit / Fill /
   Stretch; Layout → Corner: bottom right.
3. Inspector → Adjust colours: move each slider; the preview follows while
   dragging. Reset restores it.
4. Inspector → Filters: try several, lower Intensity.
5. Put a second clip above the first; Transform → Blend → Multiply/Screen.
6. Fade: set 1 s in and out; play — picture and sound fade together.
7. Library → Backgrounds: add a gradient; Background tab → switch to Solid,
   change hue and hex.
8. Export and compare with the preview.
